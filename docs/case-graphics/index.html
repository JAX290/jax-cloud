LINUX BASICS

终端基础 · 先看状态，再动手

排障顺序：系统 → 资源 → 服务 → 日志 → 备份

root@hk-01: ~
$ uname -a # 系统与内核版本
$ df -h # 磁盘使用情况
$ free -h # 内存与 swap
$ systemctl status nginx # 服务是否在运行
$ journalctl -u nginx -n 50 # 最近 50 行日志
$ ss -tlnp # 监听端口与进程
$ tar -czf backup.tar.gz data/ # 打包备份
# 改配置前先备份；改完先校验，再重启；重启后看日志确认。

排障顺序

1 · 系统与资源是否正常
2 · 服务状态是否在跑
3 · 日志报错在哪
4 · 配置与回滚改动是否可逆

三条纪律

改动前先备份
改动后先验证
出问题先回滚，再排查
